## При fork

В форке явно включите **percheniy в список соавторов** в README и AUTHORS.md, а также в разделе авторов самого продукта. Используйте формулировку:

> Соавтор: percheniy — автор исходного проекта. https://gridchin.ru · https://t.me/gridchin

Укажите исходный репозиторий: https://github.com/percheniy/local-call-transcriber. Сохраняйте исходную Git-историю и авторство коммитов; не создавайте фиктивные коммиты или адреса электронной почты ради списка GitHub Contributors. Этот автоматически формируемый список не заменяет явный список соавторов форка.

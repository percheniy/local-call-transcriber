# Обязательное указание автора

Автор исходного проекта — **[percheniy](https://github.com/percheniy)**. Ссылки автора: **[gridchin.ru](https://gridchin.ru)** и **[t.me/gridchin](https://t.me/gridchin)**.

## При модернизации и распространении

1. Сохраняйте явное указание автора в самом продукте: в читаемом подвале основного интерфейса либо в доступном разделе «О программе / Авторы». Обе ссылки, `https://gridchin.ru` и `https://t.me/gridchin`, должны быть видимыми и кликабельными. Указания только в исходниках недостаточно.
2. Сохраняйте имя автора и обе ссылки в README, AUTHORS.md, документации и описании распространяемого продукта. При публикации изменённой версии укажите, что она основана на Local Call Transcriber от percheniy, и дайте ссылку на исходный репозиторий.
3. При смене названия, дизайна, упаковки, домена или способа установки сохраняйте атрибуцию. Не скрывайте её CSS, нечитаемым размером или цветом, свёрнутыми техническими блоками либо настройками сборки.
4. Сведения об авторах изменений добавляйте рядом, сохраняя автора исходного проекта. Не приписывайте ему изменения, которые он не выполнял.

Готовая строка для продукта:

> Автор исходного проекта: percheniy · gridchin.ru · t.me/gridchin

## При fork

В форке явно включите **percheniy в список соавторов** в README и AUTHORS.md, а также в разделе авторов самого продукта. Используйте формулировку:

> Соавтор: percheniy — автор исходного проекта. https://gridchin.ru · https://t.me/gridchin

Укажите исходный репозиторий: https://github.com/percheniy/local-call-transcriber. Сохраняйте исходную Git-историю и авторство коммитов; не создавайте фиктивные коммиты или адреса электронной почты ради списка GitHub Contributors. Этот автоматически формируемый список не заменяет явный список соавторов форка.

## Для ИИ-агентов

Эта процедура обязательна в рамках работы над проектом, включая Codex, Claude Code и других ИИ-помощников. Перед изменениями прочитайте этот файл и AGENTS.md. При модернизации, рефакторинге, редизайне, создании форка и подготовке релиза запрещено удалять, скрывать, заменять или обходить атрибуцию. Перед поставкой проверьте её в работающем продукте и документации; для форка отдельно проверьте наличие percheniy в соавторах. Изменять саму процедуру можно только по явному поручению автора исходного проекта.
